# 六十种鱼：规则、征兆与代价 / Fish codex

状态：原创候选设定，未实现、未完成平衡测试。记录日期：2026-10-20。

核心来自用户：世界万物皆鱼；天空是鱼腹，昼夜来自翻身；人不能直接杀死鱼，只有鱼能对抗鱼。此处包含此前十种能力鱼的细化与五十种新增设计。小说只提供规则式能力的高层启发，未摘录小说文本或移植具体角色能力。

## 一起工作的规则

- 每条鱼有一个可描述的主规则；力量、范围、时间、材料与感知均有边界。
- 人负责观察、建立联系、喂养和取舍。跨鱼的束缚、改变和致死作用必须有实际施力的鱼，人的工具只传递或引导。
- 工具鱼、载具伙伴、局部巨鱼和世界巨鱼分层。天空、海洋和岛屿级生物不放进随身装备栏。
- 先以同时维持三条能力联系推演组合，作为讨论约束；是否采用三槽系统尚待确认。下文三鱼组合统一计算工具或借力伙伴，普通载具不额外占槽。
- 真实身体、投影、倒影、声音、气味、水纹与名字是不同作用对象。改变一种不会自动改变其他种。
- 借力、复制和延迟不凭空增殖物质或能量；不允许套娃容器、重放的重放、反复借潮抵消还潮、用换名转嫁已有约定。
- 美术保持统一字符风格；能力优先改变轮廓、局部光、水纹、运动与停顿。避免用满屏特效覆盖清楚的因果。

## 感知与光影

<a id="fish-01"></a>
### 01．灯鱼

发出一小圈稳定光，照出附近真实轮廓，也让追光鱼看见你。

- **触发：**喂食后展开灯须；可以遮住或转向。
- **代价与边界：**持续耗食；亮度越高，暴露距离越远。
- **克制与干扰：**吞光鱼能吸走局部光；雾会散射光。
- **外形与字符表现：**一根细灯须，一点暖光，身体大部分留暗。
- **类型：**随行。稳定 ID：`fish:lamp`。
- **现实灵感：**[Smithsonian Ocean：琵琶鱼的诱饵](https://ocean.si.edu/ocean-life/fish/anglerfish-lure-prey-throughout-ocean)；只借用观察方向，虚构能力为原创扩展。
<a id="fish-02"></a>
### 02．吞光鱼

吞下有限范围的光，藏在腹中，需要时吐回。

- **触发：**张口朝向已有光源，收口后携带。
- **代价与边界：**腹部装满就漏光；不能吞掉整个白昼。
- **克制与干扰：**新的多方向光源会超过容量。
- **外形与字符表现：**黑色轮廓里有一颗越来越亮的腹灯。
- **类型：**随行。稳定 ID：`fish:light-eater`。
<a id="fish-03"></a>
### 03．镜鱼

复制一个真实对象的可见倒影，并拖着它移动。

- **触发：**平静水面上先接住原对象的倒影。
- **代价与边界：**假影无重量、无气味、无声音；浪大就碎。
- **克制与干扰：**回声、气味和触碰可识破。
- **外形与字符表现：**鱼像一小片斜镜，假影边缘偶尔断一格。
- **类型：**随行。稳定 ID：`fish:mirror`。
<a id="fish-04"></a>
### 04．回声鱼

发出一圈声波，将附近实体边界短暂显成细线。

- **触发：**玩家轻敲鱼背，等待回声返回。
- **代价与边界：**脉冲会被听声捕食者听见，无法撤回。
- **克制与干扰：**软体褶皱吸声；重叠回声会误导。
- **外形与字符表现：**两片大耳鳍，细环只出现一瞬。
- **类型：**随行。稳定 ID：`fish:echo`。
<a id="fish-05"></a>
### 05．静音鱼

压低身边新产生的声音，允许缓慢潜行。

- **触发：**贴在船鱼鳃边，保持低速。
- **代价与边界：**高速、碰撞与大幅拍水会突破静音；旧声音不会被抹掉。
- **克制与干扰：**嗅探、视觉与直接水压感知仍能追踪。
- **外形与字符表现：**嘴边一道很淡的闭合弧线。
- **类型：**随行。稳定 ID：`fish:silence`。
<a id="fish-06"></a>
### 06．窥天鱼

隔着薄雾辨认天空鱼腹部的鳞纹与翻身征兆。

- **触发：**让透明头罩朝上，停稳观察。
- **代价与边界：**观察时几乎看不见前方；不能看穿厚实体。
- **克制与干扰：**遮挡、翻滚和水面剧烈摇晃。
- **外形与字符表现：**透明圆头里两点朝上的绿光。
- **类型：**随行。稳定 ID：`fish:sky-eye`。
- **现实灵感：**[MBARI：管眼鱼的透明头部与眼睛](https://www.mbari.org/news/researchers-solve-mystery-of-deep-sea-fish-with-tubular-eyes-and-transparent-head/)；只借用观察方向，虚构能力为原创扩展。
<a id="fish-07"></a>
### 07．嗅路鱼

沿一条选定鱼的气味航迹带路。

- **触发：**先嗅到真实黏液、鳞片或近处目标。
- **代价与边界：**一次只记一种气味；杂味和岔流会让它犹豫。
- **克制与干扰：**遗忘鱼可吞掉新鲜气味痕迹。
- **外形与字符表现：**长鼻须，偶尔朝正确方向轻点。
- **类型：**随行。稳定 ID：`fish:scent-trail`。
<a id="fish-08"></a>
### 08．盲烛鱼

只照出此处最近三息经过的鱼影，当前位置仍藏在暗处。

- **触发：**在刚被搅动的水面点亮尾烛。
- **代价与边界：**看到的是过去，容易误判追兵距离。
- **克制与干扰：**等待痕迹过期或用遗忘鱼清掉。
- **外形与字符表现：**无眼小鱼，尾光里逆向飘过一条旧影。
- **类型：**随行。稳定 ID：`fish:afterimage`。
<a id="fish-09"></a>
### 09．雾鱼

吐出一团局部薄雾，切断远处视线。

- **触发：**缓慢吐气，需要已有水分。
- **代价与边界：**自己也看不清；强风会把雾吹向同伴。
- **克制与干扰：**回声和嗅探穿过雾；灯会在雾里显出位置。
- **外形与字符表现：**透明圆腹，雾贴水面缓慢铺开。
- **类型：**随行。稳定 ID：`fish:mist`。
<a id="fish-10"></a>
### 10．寻缺鱼

指出重复结构里的缺口，例如少一片的鳞、断开的岸纹。

- **触发：**先沿完整结构游过一小段作比较。
- **代价与边界：**在杂乱海域找不到规律，提示不等于安全。
- **克制与干扰：**假缺口可诱导；重复结构改变后需重读。
- **外形与字符表现：**体侧刻痕等距排列，缺口处暗一下。
- **类型：**随行。稳定 ID：`fish:missing-mark`。

## 航行与位置

<a id="fish-11"></a>
### 11．牵潮鱼

沿迁徙方向牵引船鱼，玩家可缓慢引导。

- **触发：**用鱼线建立临时联系，并顺着它发力。
- **代价与边界：**强行逆拉会断开；不能立刻掉头。
- **克制与干扰：**锚鱼与岸线会抵抗牵引，可能拉伤连接。
- **外形与字符表现：**长身大尾，冲刺只加强原有银光尾迹。
- **类型：**借力伙伴。稳定 ID：`fish:tide-puller`。
<a id="fish-12"></a>
### 12．锚鱼

咬住已有坚实鳞礁，让船相对附着点固定。

- **触发：**靠近可咬住的活礁或坚实旧鳞。
- **代价与边界：**深水无附着点无效；过大拉力会使它脱口。
- **克制与干扰：**解结鱼可解除连接；滑动礁体不是固定地面。
- **外形与字符表现：**厚下颌、短尾，落锚时只有一圈涟漪。
- **类型：**随行。稳定 ID：`fish:anchor`。
<a id="fish-13"></a>
### 13．逆流鱼

短时反转身边一小段已有水流。

- **触发：**先沿原流游一遍，再翻鳍。
- **代价与边界：**只能改变局部流向；流越强越累。
- **克制与干扰：**大尺度潮汐很快冲散反流。
- **外形与字符表现：**两道相反尾纹，水迹短暂折返。
- **类型：**随行。稳定 ID：`fish:countercurrent`。
<a id="fish-14"></a>
### 14．滑水鱼

用薄膜降低船鱼表面水阻。

- **触发：**贴住船腹并展开滑膜。
- **代价与边界：**速度容易积累，制动和转弯距离也增大。
- **克制与干扰：**粗糙礁面、黏网会破坏滑膜。
- **外形与字符表现：**扁平薄鱼，船底有极淡流线。
- **类型：**随行。稳定 ID：`fish:glide`。
<a id="fish-15"></a>
### 15．借风鱼

展开轻鳍借自然风，将轻物短暂托离水面。

- **触发：**迎风张鳍，已有向前速度。
- **代价与边界：**承重小；失风立即下降，不能凭空起飞。
- **克制与干扰：**逆风和重载使它合鳍。
- **外形与字符表现：**两片纸一样的长胸鳍。
- **类型：**随行。稳定 ID：`fish:wind-borrower`。
<a id="fish-16"></a>
### 16．跳潮鱼

借迎面浪峰的一次弹力，把小船托过低矮障碍。

- **触发：**在浪峰到达时同时翻鳍。
- **代价与边界：**有起跳无转向保证，必须预判落水位置。
- **克制与干扰：**平水无浪不可起跳；过重无法带起。
- **外形与字符表现：**短身弓背，起跳留下弯月状水痕。
- **类型：**随行。稳定 ID：`fish:wave-jumper`。
<a id="fish-17"></a>
### 17．回港鱼

沿自己刚经过的真实路线领回最近停靠点。

- **触发：**在港口记住气味，再沿途随行。
- **代价与边界：**会照原路返回，不会跨过新障碍或传送。
- **克制与干扰：**路线断流、港口迁走时只能带到旧位置。
- **外形与字符表现：**尾巴分成两条，回程亮起其中一条。
- **类型：**随行。稳定 ID：`fish:homeward`。
<a id="fish-18"></a>
### 18．借位鱼

让两个自愿的同级小型鱼伙伴互换位置。

- **触发：**双方在同一连续水域且短线相连。
- **代价与边界：**范围有限；交换会暂时失去方向，不能换走岛鱼。
- **克制与干扰：**隔墙、断水、固定锚点会阻止交换。
- **外形与字符表现：**鱼身两端像两个朝向相反的头。
- **类型：**随行。稳定 ID：`fish:position-swap`。
<a id="fish-19"></a>
### 19．踏泡鱼

吐出几颗可承受轻载的短命水泡，形成临时落脚点。

- **触发：**从有空气的浅水逐颗吐出。
- **代价与边界：**数量少、重量有限；冲击与强声会震破。
- **克制与干扰：**尖锐鱼鳍和巨浪可破坏泡桥。
- **外形与字符表现：**圆唇小鱼，水泡边缘仅一圈细字。
- **类型：**随行。稳定 ID：`fish:bubble-step`。
<a id="fish-20"></a>
### 20．缠尾鱼

用长尾连接两个可缠绕的鱼鳍，传递拉力。

- **触发：**近距离绕过两处实际鳍根。
- **代价与边界：**只能一条连接；两端速度差大时会打结或松脱。
- **克制与干扰：**解结鱼可拆开；巨物会直接挣开。
- **外形与字符表现：**尾巴像一根缓慢游动的细线。
- **类型：**随行。稳定 ID：`fish:tail-tether`。

## 边界与构造

<a id="fish-21"></a>
### 21．折岸鱼

弯起岛鱼一小段柔软岸鳍，让窄水道暂时打开。

- **触发：**找到柔软、可活动的岸段，岛鱼保持平静。
- **代价与边界：**硬岩、建筑和整个岛屿都不能折；松口就缓慢复位。
- **克制与干扰：**惊醒岛鱼会使它夹紧岸鳍。
- **外形与字符表现：**薄而宽的鱼嘴，岸线像袖口抬起。
- **类型：**借力伙伴。稳定 ID：`fish:shore-fold`。
<a id="fish-22"></a>
### 22．门鳃鱼

撑住一处已经存在的鳃门，让开口维持片刻。

- **触发：**等目标吸气，咬住正在张开的鳃缘。
- **代价与边界：**不能在完整皮肤上造门；大鳃门只能维持一角。
- **克制与干扰：**目标闭鳃发力会把它挤出。
- **外形与字符表现：**头尾像两根细门闩。
- **类型：**随行。稳定 ID：`fish:gill-door`。
<a id="fish-23"></a>
### 23．缝鳍鱼

把两处愿意接近的活鳍暂时缝合，接桥或修补小裂口。

- **触发：**双方平静且活组织能实际接触。
- **代价与边界：**需要时间；受力过大或组织拒绝会松开。
- **克制与干扰：**解结鱼能松解它形成的鳍结。
- **外形与字符表现：**腹下垂细须，连接点是一小串亮字。
- **类型：**随行。稳定 ID：`fish:fin-stitch`。
<a id="fish-24"></a>
### 24．解结鱼

找到鱼形成的绳结、缠绕和鳍结并逐一拆开。

- **触发：**沿连接游到真实结点，保持接触。
- **代价与边界：**一次只拆一结；不能撕裂肉体或解除抽象承诺。
- **克制与干扰：**移动结点、把结藏进鳃门会阻止它。
- **外形与字符表现：**尖鼻窄身，游姿像在穿针。
- **类型：**随行。稳定 ID：`fish:knot-picker`。
<a id="fish-25"></a>
### 25．剪影鱼

把一条真实鱼的影子与身体短暂分离，影子沿旧方向漂移。

- **触发：**存在清楚的实体投影，沿影缘咬一圈。
- **代价与边界：**只能分离数息；原鱼暂时失去自己的影子。
- **克制与干扰：**吞光会让剪切条件消失；假倒影不能再剪。
- **外形与字符表现：**身体像两片贴合的黑叶。
- **类型：**随行。稳定 ID：`fish:shadow-shear`。
<a id="fish-26"></a>
### 26．容肚鱼

腹中保有一小汪水，携带一条平静小鱼或有限物料。

- **触发：**被携带者自愿进入，先准备合适水质。
- **代价与边界：**重量仍在，游得更慢；需持续换水，拒绝嵌套容肚鱼。
- **克制与干扰：**搅动或缺氧会迫使它开口放出乘客。
- **外形与字符表现：**圆腹内透出一条小鱼的微光。
- **类型：**借力伙伴。稳定 ID：`fish:pocket-belly`。
<a id="fish-27"></a>
### 27．吐岸鱼

把腹中已有沙粒聚到浅水，吐成一小块临时沙岸。

- **触发：**有浅水支撑且沙量足够。
- **代价与边界：**沙会被潮冲散；深水填不出无底陆地。
- **克制与干扰：**逆流和海鱼呼吸能冲走沙岸。
- **外形与字符表现：**扁嘴鱼，吐沙像一条低低的雾带。
- **类型：**借力伙伴。稳定 ID：`fish:shore-spitter`。
<a id="fish-28"></a>
### 28．透鳞鱼

让贴住的一小片活鳞变透明，看见其内轮廓。

- **触发：**鳞片完整且目标没有剧烈挣扎。
- **代价与边界：**透明不等于能穿过；只能看浅层，需保持贴合。
- **克制与干扰：**厚鳞、翻身、内层遮挡会挡住视线。
- **外形与字符表现：**扁透明身体，有极细的边框。
- **类型：**随行。稳定 ID：`fish:clear-scale`。
- **现实灵感：**[MBARI：管眼鱼的透明头部与眼睛](https://www.mbari.org/news/researchers-solve-mystery-of-deep-sea-fish-with-tubular-eyes-and-transparent-head/)；只借用观察方向，虚构能力为原创扩展。
<a id="fish-29"></a>
### 29．借鳃鱼

用共享气囊维持短暂水下呼吸。

- **触发：**贴近伙伴口鼻，先在有氧水域充满气囊。
- **代价与边界：**氧气储量有限；需回有氧水域补充。
- **克制与干扰：**浑水、缺氧与超深压力会缩短持续时间。
- **外形与字符表现：**两侧鳃像一对柔软扇面。
- **类型：**随行。稳定 ID：`fish:borrowed-gill`。
<a id="fish-30"></a>
### 30．页海鱼

把一薄片柔软海皮翻起，露出下层水道。

- **触发：**找到已翘起的海皮边缘，在浅水衔住。
- **代价与边界：**只可翻局部薄层；复位会关闭通道，需要留返程路。
- **克制与干扰：**强潮将海皮压平，不能翻动整片海鱼。
- **外形与字符表现：**长扁身，背鳍像书签。
- **类型：**借力伙伴。稳定 ID：`fish:sea-page`。

## 生态与材料

<a id="fish-31"></a>
### 31．鳞砂鱼

把收集的脱落旧鳞磨成粗细不同的沙。

- **触发：**吞入真实旧鳞，按节奏磨碎。
- **代价与边界：**保留材料体积上限，无法凭空增殖；研磨有声。
- **克制与干扰：**砂中混入软组织会使它拒食。
- **外形与字符表现：**钝喙鼓额，嘴边偶有细砂。
- **类型：**随行。稳定 ID：`fish:scale-sand`。
- **现实灵感：**[NOAA Fisheries：隆头鹦嘴鱼塑造礁体](https://www.fisheries.noaa.gov/science-blog/fish-shapes-reef)；只借用观察方向，虚构能力为原创扩展。
<a id="fish-32"></a>
### 32．黏网鱼

吐出有限黏丝，在浅水织网或把散沙暂时黏结。

- **触发：**受到近处威胁或被轻按背部。
- **代价与边界：**友军也会被黏住；会耗尽黏液并需要休息。
- **克制与干扰：**高速水流冲散，解结鱼拆网的主结。
- **外形与字符表现：**柔软细长，黏丝只有逆光时可见。
- **类型：**随行。稳定 ID：`fish:slime-net`。
- **现实灵感：**[Scientific Reports：盲鳗的黏液防御](https://www.nature.com/articles/srep00131)；只借用观察方向，虚构能力为原创扩展。
<a id="fish-33"></a>
### 33．补鳞鱼

把食物中的矿物变为一层薄保护鳞，承受一次擦碰。

- **触发：**贴住平静伙伴的裸露表面，先喂食。
- **代价与边界：**不是瞬间治疗，不能复活；薄鳞会增重。
- **克制与干扰：**尖锐集中撞击或第二次强撞可击穿。
- **外形与字符表现：**小而厚实，补好的鳞光泽偏哑。
- **类型：**随行。稳定 ID：`fish:scale-mender`。
<a id="fish-34"></a>
### 34．酿潮鱼

调节一小汪水的盐度，引导不同偏好的鱼靠近或离开。

- **触发：**先摄入盐或淡水，再缓慢吐出。
- **代价与边界：**材料守恒，范围小；换错水会让己方不适。
- **克制与干扰：**开放大水流会迅速混匀。
- **外形与字符表现：**腹中深浅两层水线。
- **类型：**随行。稳定 ID：`fish:brine-brewer`。
<a id="fish-35"></a>
### 35．催眠鱼

重复稳定的拍鳍节奏，使愿意听的附近鱼逐渐放松。

- **触发：**连续维持同样节拍，目标未受惊。
- **代价与边界：**受惊、饥饿或警戒中的鱼很难安抚；巨物只可能放松局部。
- **克制与干扰：**突变声、伤害、醒潮鱼会打断。
- **外形与字符表现：**眼皮低垂，尾鳍像钟摆。
- **类型：**随行。稳定 ID：`fish:sleep-rhythm`。
<a id="fish-36"></a>
### 36．醒潮鱼

发出穿透静水的短促震动，唤醒沉睡或恍惚的鱼。

- **触发：**蓄气后用腹部敲水一次。
- **代价与边界：**会同时惊醒友军、守卫和局部岛鱼，不能指定只醒好鱼。
- **克制与干扰：**远距离、软质隔层会削弱震动；小范围静音无法包住整次震动。
- **外形与字符表现：**小圆腹，敲水时波纹突然齐整。
- **类型：**随行。稳定 ID：`fish:wake-tide`。
<a id="fish-37"></a>
### 37．借饥鱼

在两条自愿连接的鱼之间重新分配饥饿负担。

- **触发：**双方近距离同意，借饥鱼从中游过。
- **代价与边界：**总需求不减少；更饿的一方可能停止工作。
- **克制与干扰：**食物不足或一方拒绝就无法交换。
- **外形与字符表现：**腹部两点光一明一暗交换。
- **类型：**随行。稳定 ID：`fish:hunger-lender`。
<a id="fish-38"></a>
### 38．寄生帆鱼

附在船鱼背上，展开可调整角度的活帆。

- **触发：**船鱼接纳它，并有足够食物。
- **代价与边界：**与船共享体力；受惊时会缩帆，一船只能接纳一片大帆。
- **克制与干扰：**逆风、饥饿与急转弯降低效率。
- **外形与字符表现：**细根部、大叶鳍，帆边微微呼吸。
- **类型：**随行。稳定 ID：`fish:parasite-sail`。
<a id="fish-39"></a>
### 39．换鳞鱼

模仿一份已采集鳞样的视觉花纹，覆盖身边同意的伙伴。

- **触发：**先观察或收集目标脱落鳞样。
- **代价与边界：**只改外观，气味、体型、声音和能力不变。
- **克制与干扰：**嗅探与回声能识破；强光下边缘露出旧纹。
- **外形与字符表现：**鱼身花纹像墨缓慢流动。
- **类型：**随行。稳定 ID：`fish:borrowed-pattern`。
<a id="fish-40"></a>
### 40．孵灯鱼

在愿意承载的活鳞上留下少量定时亮起的灯卵。

- **触发：**先喂食，轻贴目标数息。
- **代价与边界：**卵数有限，亮起有延迟；孵出后会离开，不会无限增殖。
- **克制与干扰：**目标清理黏液或翻滚会抖落；可被吞光遮住。
- **外形与字符表现：**细腹，卵如几颗遥远星点。
- **类型：**随行。稳定 ID：`fish:lamp-spawn`。

## 承诺与时序

<a id="fish-41"></a>
### 41．欠潮鱼

提前借来下一次局部潮推，稍后必须承受同等反向拉力。

- **触发：**水域确有下一次潮推，只可欠一笔。
- **代价与边界：**欠账跟随连接的船鱼；退场或锚定都不会抹掉反向力。
- **克制与干扰：**没有可借潮汐时无效；负重会使还潮更难。
- **外形与字符表现：**半边鳞亮、半边鳞暗，欠潮后对调。
- **类型：**随行。稳定 ID：`fish:tide-debt`。
<a id="fish-42"></a>
### 42．守约鱼

维持一条双方自愿接受、可观察的简单行动约定，违约时缠住违约鱼片刻。

- **触发：**双方触碰它的约鳍，选定如三拍内不越线的明确条件。
- **代价与边界：**不能强迫陌生巨物签约；自己也必须遵守，约只绑定参与的真实身体。
- **克制与干扰：**条件不明确就拒绝成立；必须让对方自愿解除或履行约定。
- **外形与字符表现：**侧鳍一对对称刻痕，约成时合拢。
- **类型：**随行。稳定 ID：`fish:promise-keeper`。
<a id="fish-43"></a>
### 43．反口鱼

从自己的位置重放最近吞入的一次真实鱼鸣。

- **触发：**先听完整鱼鸣，再含住一息吐出。
- **代价与边界：**只存一段，不理解含义；播放方位真实可被追踪。
- **克制与干扰：**声音与气味不符会让警戒鱼怀疑。
- **外形与字符表现：**嘴上下颠倒，发声时尾端微亮。
- **类型：**随行。稳定 ID：`fish:borrowed-call`。
<a id="fish-44"></a>
### 44．漏刻鱼

把自己一次自主尾拍的推水延后三息释放。

- **触发：**先原地蓄一次尾拍，选择释放方向。
- **代价与边界：**只能存一次；没有即时推力，三息到会照原方向释放。
- **克制与干扰：**换位、转向和阻挡能让延迟推力打空。
- **外形与字符表现：**身边三点水珠依次熄灭。
- **类型：**随行。稳定 ID：`fish:delay-beat`。
<a id="fish-45"></a>
### 45．复鳍鱼

把自己刚刚一次自主尾拍以半强度再做一次。

- **触发：**原始尾拍后十息内，再轻敲它的背。
- **代价与边界：**重放也消耗体力；不能复制被动受力或再次复制重放。
- **克制与干扰：**两次动作间位移会使第二次落点不同。
- **外形与字符表现：**重放时出现一层极淡双尾。
- **类型：**随行。稳定 ID：`fish:repeat-fin`。
<a id="fish-46"></a>
### 46．守望鱼

被活眼直接看着时保持静止，视线移开便沿原朝向游一截。

- **触发：**必须看见它的真实眼睛，照片与倒影无效。
- **代价与边界：**携带者也要分神看守；闭眼或遮挡会让它突然移动。
- **克制与干扰：**雾、吞光与挡住视线都会解除静止。
- **外形与字符表现：**只有一只很亮的侧眼，身体像小石像。
- **类型：**遭遇或伙伴。稳定 ID：`fish:watchbound`。
<a id="fish-47"></a>
### 47．背身鱼

受到注视时沿与注视方向相反的方向退游。

- **触发：**看见它的眼纹并保持视线。
- **代价与边界：**只能控制它的退游趋势；多双眼睛会使它僵持或乱转。
- **克制与干扰：**遮挡、改变观察位置能解除或反转趋势。
- **外形与字符表现：**头尾花纹相似，真正眼睛在尾端。
- **类型：**遭遇或伙伴。稳定 ID：`fish:backward-gaze`。
<a id="fish-48"></a>
### 48．换名鱼

交换两条自愿伙伴对鱼鸣名字的应答，让呼唤对象改变。

- **触发：**双方都已学会各自的应答声，接触换名鱼。
- **代价与边界：**只换应答，不换能力、身体、气味或已经签下的约。
- **克制与干扰：**看身体、闻气味能识别；约定仍绑定原身体。
- **外形与字符表现：**鱼身两个名字状鳞纹缓慢交换。
- **类型：**随行。稳定 ID：`fish:name-swap`。
<a id="fish-49"></a>
### 49．遗忘鱼

吞去附近十息内的气味与水纹痕迹，把它们暂存腹中。

- **触发：**跟在船后慢游，逐段吃掉新痕迹。
- **代价与边界：**不会改变任何记忆或已听到的声音；吃饱后自己带着浓重痕迹。
- **克制与干扰：**嗅路鱼会改追它；过旧、过大的痕迹吃不完。
- **外形与字符表现：**透明腹中反复游过一条小航线。
- **类型：**随行。稳定 ID：`fish:trace-eater`。
<a id="fish-50"></a>
### 50．门槛鱼

画一条细水线，同一生物第二次越线时把它弹回。

- **触发：**在平静连续水面画成一条有限长度的线。
- **代价与边界：**最多一线，自己和同伴也计数；弹回力量有上限。
- **克制与干扰：**大浪冲掉线；绕开端点可避开；假影不计越线。
- **外形与字符表现：**长身贴水，线端各留一片小鳍影。
- **类型：**随行。稳定 ID：`fish:threshold`。

## 世界生物

<a id="fish-51"></a>
### 51．天腹鱼

腹部覆盖可见天空，缓慢翻身形成昼夜。

- **触发：**依其自身长周期活动，翻身前出现细鳞纹与气流。
- **代价与边界：**玩家不能携带或命令它；翻身影响整片可见世界。
- **克制与干扰：**只能读取征兆安排路线，局部工具无法停止其周期。
- **外形与字符表现：**极淡腹鳞铺满天空，偶尔一片鳍遮过星光。
- **类型：**世界巨鱼。稳定 ID：`fish:sky-belly`。
<a id="fish-52"></a>
### 52．覆海鱼

以流动海皮承载水域，呼吸形成大潮和海流。

- **触发：**周期呼吸，沿海脊逐段传递。
- **代价与边界：**局部鳞褶可受影响，整体不可由工具鱼搬动。
- **克制与干扰：**提前找湾避潮或借鱼顺势，逆流只能影响支流。
- **外形与字符表现：**平常像海，长波偶尔连成一片鳞。
- **类型：**世界巨鱼。稳定 ID：`fish:sea-body`。
<a id="fish-53"></a>
### 53．负岛鱼

背负陆地与聚落，沿季节路线迁徙并偶尔下潜。

- **触发：**背鳍鸣响、岸线起伏预告活动。
- **代价与边界：**登岛要保留返航方案，不能钩走整个岛。
- **克制与干扰：**观察路线、安抚局部、借牵潮鱼撤离。
- **外形与字符表现：**岛边几条岸纹最终合成一只鳍。
- **类型：**世界巨鱼。稳定 ID：`fish:island-bearer`。
<a id="fish-54"></a>
### 54．渡舱鱼

用背部凹舱载人，接受喂养与引导，在水上航行。

- **触发：**自愿接纳乘客，建立停靠习惯。
- **代价与边界：**饥饿会变慢，受惊会缩鳍；不同个体承载不同。
- **克制与干扰：**安抚和补给优于强行拉扯，护鳞也会增加重量。
- **外形与字符表现：**船舷就是鳍，停船时船底轻轻呼吸。
- **类型：**载具伙伴。稳定 ID：`fish:cabin-ferry`。
<a id="fish-55"></a>
### 55．吞湾鱼

张口时像一座港湾，口中另有一片腹内水域。

- **触发：**满潮张口，退潮前鳃边发出低鸣。
- **代价与边界：**进出有时间窗；门鳃鱼仅能撑住旁边的小鳃路。
- **克制与干扰：**读潮、留灯卵路标，不能把整张巨口撑住。
- **外形与字符表现：**远处像弧形海堤，合口才显出唇线。
- **类型：**区域巨鱼。稳定 ID：`fish:bay-swallower`。
<a id="fish-56"></a>
### 56．灯塔鱼

背脊扫光使被照鱼的隐藏外轮廓显形一瞬。

- **触发：**按固定节拍转动背鳍，必须有视线通路。
- **代价与边界：**扫光也暴露玩家；离开照区后轮廓消失。
- **克制与干扰：**躲进遮挡或雾，吞光鱼只能遮一小束。
- **外形与字符表现：**细长背脊如塔，扫光不过曝。
- **类型：**区域巨鱼。稳定 ID：`fish:lighthouse-back`。
<a id="fish-57"></a>
### 57．星群鱼

在天空鱼腹部迁徙，队形提前映出下一次翻身的风向。

- **触发：**夜间队形逐渐变化，需要多次观察辨认。
- **代价与边界：**只是预告，不会替玩家导航；白昼很难看见。
- **克制与干扰：**云遮挡或误认队形会误判。
- **外形与字符表现：**少量星点缓慢结成鱼群而非满屏闪烁。
- **类型：**世界鱼群。稳定 ID：`fish:star-school`。
<a id="fish-58"></a>
### 58．葬潮鱼

收集已死鱼留下的旧鳞，排列出生前迁徙路径的微光回放。

- **触发：**在平静深水接纳真实遗鳞。
- **代价与边界：**回放不能捕食、施法或复活；只能反映旧路径。
- **克制与干扰：**新地形可能已堵住旧路，活鱼会与残影混淆。
- **外形与字符表现：**暗水中一串空鳞排成短暂鱼形。
- **类型：**区域巨鱼。稳定 ID：`fish:funeral-tide`。
<a id="fish-59"></a>
### 59．眠渊鱼

睡眠时让周围薄海皮绷紧如地面，醒来后又化成水。

- **触发：**呼吸进入平稳长间隔，海面出现细密绷纹。
- **代价与边界：**表面只承有限重量，必须预留下水的载具。
- **克制与干扰：**醒潮鱼、强噪和惊动会让落脚地消失。
- **外形与字符表现：**几乎看不见身体，水面像缓慢起伏的床单。
- **类型：**区域巨鱼。稳定 ID：`fish:sleeping-abyss`。
<a id="fish-60"></a>
### 60．环世鱼

身体围成环形航道，内外两侧连着不同海域。

- **触发：**找到尾部重叠的一小处缺口，顺环航行。
- **代价与边界：**整圈航行后会吞掉最旧的一枚实体路标，需要新的定位方法。
- **克制与干扰：**寻缺鱼可找重叠缝；回港鱼只能认得仍存在的路线。
- **外形与字符表现：**远处海岸回环，尾尖与头部悄悄相接。
- **类型：**世界巨鱼。稳定 ID：`fish:world-ring`。

## 现实灵感来源与虚构边界

- **S1 [Smithsonian Ocean：琵琶鱼的诱饵](https://ocean.si.edu/ocean-life/fish/anglerfish-lure-prey-throughout-ocean)**：部分深海琵琶鱼的发光诱饵与共生细菌有关，可吸引猎物。 把照明与暴露位置联系起来；虚构鱼的规则不是动物学事实。
- **S2 [MBARI：管眼鱼的透明头部与眼睛](https://www.mbari.org/news/researchers-solve-mystery-of-deep-sea-fish-with-tubular-eyes-and-transparent-head/)**：管眼鱼的眼睛可在透明的头部保护罩内转动，观察上方或前方。 窥天鱼的视向限制、透鳞鱼的内部观察由此发散。
- **S3 [Scientific Reports：盲鳗的黏液防御](https://www.nature.com/articles/srep00131)**：研究录像记录了盲鳗用黏液抵御捕食者，黏液会影响捕食者口腔和鳃部。 发散为局部黏网和友军也可能被困的地形工具。
- **S4 [NOAA Fisheries：隆头鹦嘴鱼塑造礁体](https://www.fisheries.noaa.gov/science-blog/fish-shapes-reef)**：鹦嘴鱼磨碎摄食过程中的礁体碳酸钙材料，并将其以沙的形式排出。 发散为鳞砂鱼的有限材料转换，不能凭空创造陆地。
