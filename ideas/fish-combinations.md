# 带着三种鱼，会发生什么？ / Fish combinations

状态：待比较的原创玩法推演，未实现，未完成平衡或可玩性验证。日期：2026-10-20。

先用“同时维持三条能力联系”作设计约束。普通船鱼作为载具背景；天空鱼、海鱼和岛鱼等世界生物不计作可以装进栏位的工具。是否采用三槽系统还需要讨论。

组合要改变可做的事情、操作顺序、位置或风险。每项都从[六十种鱼](fish-codex.md)的已有规则推导，不临时给第三条鱼增加万能技能。数值、距离和秒数只用于推演。

## 十五套三鱼组合（含三种危险共生）

<a id="combo-01"></a>
### 01．会急刹的远航者：牵潮鱼＋锚鱼＋滑水鱼

**想解决的事情：**快速穿越危险水道，并在有限位置停下。

**实际过程：**滑水鱼降低水阻，牵潮鱼把船带入高速；提前收膜减速，接近可咬礁点后让锚鱼附着。

**带来的选择：**玩家读海岸、挑制动点；同一速度既是优势也是负担，可选择滑过危险或停下来探索。

**会怎样翻车：**深水没有锚点；不收滑膜就强锚，会让拉力骤增、锚鱼脱口，不能无限固定巨物。

**最小验证：**一个弯道、两个锚点、一条牵潮鱼，验证两条不同路线。

<a id="combo-02"></a>
### 02．把自己的影子卖给海：灯鱼＋镜鱼＋剪影鱼

**想解决的事情：**穿过只追逐可见影子的捕食者领地。

**实际过程：**用灯鱼照出船鱼真实影子，再由剪影鱼分离它；镜鱼拖走另一份可见倒影，引开第二个方向的视线。

**带来的选择：**玩家在几息内没有自己的影子，要决定朝哪个方向撤离，哪份影先暴露给追兵。

**会怎样翻车：**灯、真实影和假倒影作用不同；假影没有气味和声音；剪影结束前没离开，真实身体重新暴露。

**最小验证：**一盏灯、一个影猎者、一小段平静水面。

<a id="combo-03"></a>
### 03．会暴露自己的测绘师：回声鱼＋静音鱼＋遗忘鱼

**想解决的事情：**在雾里探路后摆脱多感官追踪。

**实际过程：**先用回声读取实体边界，听声鱼得到一次位置线索；船离开发声点后低速静音，遗忘鱼再逐段吞去气味与尾迹。

**带来的选择：**一次主动探测换来信息和追兵；玩家要决定下一次脉冲何时值得冒险。

**会怎样翻车：**静音不能抹掉已经发出的声，遗忘鱼也不会删除敌方记忆；吃饱后遗忘鱼自己成了气味目标。

**最小验证：**一处雾中岔道，一只听声鱼和一只嗅路鱼。

<a id="combo-04"></a>
### 04．安静地走过一座会破的桥：踏泡鱼＋锚鱼＋静音鱼

**想解决的事情：**短距离离船探索，在回程前保持落脚点。

**实际过程：**锚鱼固定起点，踏泡鱼依次吐出承重水泡；静音鱼让伙伴小幅移动时不轻易惊动声源。

**带来的选择：**出发前分配泡数与重量，可把装备留在船上，回程需要预留泡和体力。

**会怎样翻车：**静音只能压低自身新声，不能挡外界巨响；大浪、过重或尖鳍仍会破泡。

**最小验证：**四颗水泡、轻重两件货物、一次可预告的外部冲击。

<a id="combo-05"></a>
### 05．随身携带一小段海岸：鳞砂鱼＋吐岸鱼＋黏网鱼

**想解决的事情：**为救援或休息造一处短命浅滩。

**实际过程：**鳞砂鱼把已有旧鳞磨成沙，吐岸鱼在浅水堆起小岸，黏网鱼把易散部分暂时黏住。

**带来的选择：**玩家选择沙量、落脚位置和保存时间；退潮后可以回收一部分材料。

**会怎样翻车：**黏网会困住伙伴，深水没有足够材料；黏结只延缓冲散，不能永久创造土地。

**最小验证：**一块浅滩，固定沙量，两种潮流强度。

<a id="combo-06"></a>
### 06．从一条鱼的鳃里进去：透鳞鱼＋门鳃鱼＋借鳃鱼

**想解决的事情：**进入有既存鳃隙的局部巨鱼体表水道。

**实际过程：**透鳞鱼先观察内层活动与危险，等吸气窗口让门鳃鱼撑住已有开口，借鳃鱼供给短时呼吸。

**带来的选择：**玩家先侦察再决定进不进，氧气和开口时间共同限制深入距离。

**会怎样翻车：**透明不移除碰撞；门鳃撑不住整张巨口；氧气用尽前必须返回有氧区。

**最小验证：**一处随呼吸开合的小鳃门，一段有限水道。

<a id="combo-07"></a>
### 07．一人指挥一整湾的睡意：反口鱼＋催眠鱼＋醒潮鱼

**想解决的事情：**引开守卫、安抚目标，并主动打破原来的沉睡格局。

**实际过程：**反口鱼在选定位置重放真实鱼鸣，引来能识别这段声的鱼；催眠鱼在安全节拍中慢慢安抚；醒潮鱼在需要转移注意时敲水。

**带来的选择：**声音的方位、重复与突变分别影响目标；玩家可制造分流，也可能惊动整片湾。

**会怎样翻车：**反口鱼不懂鸣叫含义，可能招来另一种鱼；醒潮会打断己方催眠并惊醒附近生物。

**最小验证：**两只对声音反应不同的鱼，一小片水域。

<a id="combo-08"></a>
### 08．向下一次海潮借一脚油门：欠潮鱼＋逆流鱼＋锚鱼

**想解决的事情：**提前越过险流，并有计划地承受还潮。

**实际过程：**欠潮鱼借来下一次潮推，逆流鱼短时调整出口支流；找到真实礁点后锚住，等反向力到来。

**带来的选择：**同一笔债可在不同地点偿还，玩家选择把风险放在航程的哪一段。

**会怎样翻车：**逆流只改局部水流，锚只承受力；两者都不会取消债务，超载仍会脱口或断联。

**最小验证：**一次前推与一次反拉，一个安全湾和一个危险出口。

<a id="combo-09"></a>
### 09．让追你的鱼撞上自己的第二次：门槛鱼＋缠尾鱼＋反口鱼

**想解决的事情：**在小范围内摆脱可被有限拉力影响的追兵。

**实际过程：**反口鱼引目标第一次跨过门槛线；缠尾鱼在短暂近距牵动它转向，让它第二次跨同一线。

**带来的选择：**利用位置与计数弹回目标，可把对抗做成路线谜题，玩家也要记得自己的越线次数。

**会怎样翻车：**大鱼会挣开缠尾；敌人可绕线端；队友误跨第二次也会被弹回，假影不计次数。

**最小验证：**一条门槛线，两条绕行路线，一只中小追兵。

<a id="combo-10"></a>
### 10．一座会饿的移动救护站：容肚鱼＋借饥鱼＋补鳞鱼

**想解决的事情：**护送受惊后已被安抚的小鱼通过危险水域。

**实际过程：**容肚鱼提供适合水质的临时避难水；补鳞鱼给乘客或载体做薄保护；借饥鱼在愿意承担的伙伴间转移补给负担。

**带来的选择：**救援让载具更重、更饿，玩家决定先救谁、把最后一口食物给谁。

**会怎样翻车：**借饥不会创造食物；保护鳞不能治愈重伤或复活；容肚鱼需要换水，重量照常存在。

**最小验证：**一条自愿登舱的鱼，一次可预告擦碰，有限食物。

<a id="combo-11"></a>
### 11．把一条船借给风：寄生帆鱼＋借风鱼＋跳潮鱼

**想解决的事情：**越过低矮礁脊，并准确落回可通航水面。

**实际过程：**寄生帆鱼调角积累前速，跳潮鱼在浪峰托起小船，借风鱼在离水后短时稳定轻载滑行。

**带来的选择：**玩家在载重、风向、起跳点和落点之间做取舍，能放弃部分货物换一条路线。

**会怎样翻车：**自然风会变，借风承重有限；三鱼共享补给，起跳成功也可能落到礁上。

**最小验证：**一处低礁，两种风向，一条轻船与有限货物。

<a id="combo-12"></a>
### 12．三息之后，它在另一边拍水：漏刻鱼＋借位鱼＋锚鱼

**想解决的事情：**在开阔水域改变一次延迟推力的发生位置。

**实际过程：**锚鱼把船固定在实际附着点；漏刻鱼蓄下原方向的一次尾拍；三息到来前借位鱼让漏刻鱼与自己互换位置，推力在新位置按旧方向释放。

**带来的选择：**玩家预判方向、距离和倒计时，能从侧面推开障碍鱼或把伙伴送向出口。

**会怎样翻车：**不能隔墙交换；不能交换世界巨鱼；方向已经锁定，换错位置会把伙伴推入危险，也不能复制能量。

**最小验证：**两处互相可见的水点，一块可被鱼推力带动的软障碍。

<a id="combo-13"></a>
### 13．你得亲自看守自己的黑夜：灯鱼＋吞光鱼＋守望鱼

**想解决的事情：**同时携带照明、遮光与一条靠注视保持静止的鱼。

**实际过程：**灯鱼让你看见守望鱼的真实眼睛；吞光鱼一旦遮住这束光，直视中断，守望鱼就沿旧朝向移动；重新放光后才能再次看住。

**带来的选择：**玩家想隐蔽就要先安排守望鱼朝向，把它短暂活动当作可利用的位移，也要决定何时值得暴露光。

**会怎样翻车：**三鱼不自动抵消代价；吞光鱼储满又会漏光，守望鱼可能在视线被挡的一刻撞乱布置，其他活眼直视可暂时接替看守。

**最小验证：**一盏可控灯、一只守望鱼、一个能藏身也会挡视线的礁点。

<a id="combo-14"></a>
### 14．你布的陷阱，会沿鱼线传回自己身上：缠尾鱼＋门槛鱼＋解结鱼

**想解决的事情：**利用有限弹回力摆脱追兵，同时避免被同一连接拖回去。

**实际过程：**门槛鱼画线，缠尾鱼连接船鱼与追兵可缠绕的鳍；目标第二次越线被弹回时，拉力会沿连接传向船；玩家要派解结鱼在恰当时刻拆掉主结。

**带来的选择：**陷阱成功不等于自己安全，玩家在保持牵制与提前解除连接之间取舍，也可故意借反拉改变船向。

**会怎样翻车：**解结需要到真实结点，可能来不及；太早拆结追兵可绕线，太晚则自己也被拉走或触发己方门槛计数。

**最小验证：**一根实际连接、一条门槛线、一处可以接近也可能被挡住的主结。

<a id="combo-15"></a>
### 15．救醒一条鱼，先惊醒了装着你的那条：门鳃鱼＋借鳃鱼＋醒潮鱼

**想解决的事情：**进入宿主鳃路救出一条沉睡小鱼。

**实际过程：**等吸气时门鳃鱼撑住小开口，借鳃鱼提供有限氧气；醒潮鱼把小鱼唤醒，也可能惊动宿主的局部呼吸，使鳃门提前收紧。

**带来的选择：**玩家可以先引导沉睡小鱼靠近出口再唤醒，或先唤醒争取它自行游出；救援顺序改变逃生难度。

**会怎样翻车：**开口不是永久门，氧气与门鳃承受力都有限；宿主惊动后的收鳃不能靠继续敲水解决。

**最小验证：**一处会被惊动收紧的鳃门、一条愿意被引导的睡鱼、有限氧气。

## 二十四条配合、互克与无效捷径

| 鱼之间的关系 | 类型 | 结果 |
|---|---|---|
| 灯鱼 ＋ 镜鱼 | 配合 | 灯提供真实倒影的来源，镜移动假影；真实灯光也会暴露出发位置。 |
| 灯鱼 ＋ 吞光鱼 | 冲突 | 吞光会吃掉灯的局部照明；储满后吞光鱼漏光，无法无限隐蔽。 |
| 回声鱼 ＋ 静音鱼 | 冲突 | 静音范围里发回声会削弱探测；适合先发声、离开发声点，再静音。 |
| 嗅路鱼 ＋ 遗忘鱼 | 克制 | 遗忘鱼吞去气味航迹后，嗅路鱼失去原路，但可能改追它带味的腹部。 |
| 窥天鱼 ＋ 雾鱼 | 有限配合 | 窥天鱼能辨薄雾里的天空征兆；浓雾、实体与剧烈晃动仍然阻挡。 |
| 守望鱼 ＋ 镜鱼 | 无效捷径 | 镜里的眼睛不是活眼直视，无法让守望鱼永久静止。 |
| 借位鱼 ＋ 锚鱼 | 冲突 | 被锚定的伙伴不能直接借位；必须先承受解除锚定后的风险。 |
| 缠尾鱼 ＋ 解结鱼 | 克制 | 解结鱼可拆缠尾形成的主结，也会拆掉玩家自己的有效牵引。 |
| 缝鳍鱼 ＋ 解结鱼 | 克制 | 解结可松开鳍结，不能撕裂原本完整的活组织。 |
| 鳞砂鱼 ＋ 吐岸鱼 | 配合 | 旧鳞变沙，再由吐岸鱼布置；总材料量有限。 |
| 吐岸鱼 ＋ 黏网鱼 | 配合 | 黏丝把散沙暂时黏住，伙伴同样可能被网困住。 |
| 容肚鱼 ＋ 酿潮鱼 | 双刃配合 | 容肚鱼的水可被调节，适合某种乘客也可能伤害另一种乘客。 |
| 催眠鱼 ＋ 醒潮鱼 | 克制 | 醒潮打断催眠，并可能叫醒不想叫醒的岛鱼局部。 |
| 借饥鱼 ＋ 寄生帆鱼 | 资源牵制 | 寄生帆提高船的补给压力；借饥只能转移压力，不能凭空供给。 |
| 欠潮鱼 ＋ 锚鱼 | 双刃配合 | 锚使船不易被还潮拉走，但反向力仍会作用在连接上。 |
| 换名鱼 ＋ 守约鱼 | 无效捷径 | 换名只改应答声，不能把身体绑定的承诺转给另一条鱼。 |
| 漏刻鱼 ＋ 复鳍鱼 | 限制 | 各自产生自己的尾拍；不能复制对方、被动受力或重放产物，不能形成无限推力。 |
| 门槛鱼 ＋ 镜鱼 | 无效捷径 | 假倒影不算真实生物越线，不能替自己消耗一次通行。 |
| 雾鱼 ＋ 灯鱼 | 冲突 | 雾挡住轮廓，同时会把灯光散成可见光团。 |
| 眠渊鱼 ＋ 醒潮鱼 | 危险关系 | 醒潮可能扰动眠渊鱼的睡眠，让原本能落脚的薄海皮重新变水。 |
| 天腹鱼 ＋ 吞光鱼 | 尺度限制 | 吞光只作用于局部，不能吞掉天空鱼、命令天黑或停止翻身。 |
| 缝鳍鱼 ＋ 补鳞鱼 | 配合 | 先修补可接触的小裂口，再添薄保护鳞；增重与修补时间仍在。 |
| 负岛鱼 ＋ 回港鱼 | 冲突 | 回港鱼认的是经过的路线；岛鱼迁走后，它只能带到原来的港口位置。 |
| 孵灯鱼 ＋ 回港鱼 | 配合 | 灯卵作为短时可见路标辅助回程，孵离后仍要重新定位。 |

## 约束与反例

- “三种鱼都有用”不等于“三种鱼同时开”。先后切换、提前准备和主动停用都能形成操作。
- 遮住视觉不能自动消除气味、声音、尾流和已经泄露的信息。
- 材料、食物、重量、氧气、容量和力的反作用继续存在；复制重放也消耗体力。
- 多鱼同时工作可能争夺同一块皮肤、同一处附着点或注意力，需要先确定连接位置。
- 强组合也应有环境边界：平水、浅水、有氧、自然风、实际礁点等条件可改变适用性。
- 工具鱼对巨物最多影响可接触的局部；不把局部静音、吞光、开门直接放大成控制整个世界。
- 人的直接攻击仍不能杀鱼。死亡若发生，需要明确哪条鱼施加了何种可反制作用；本轮组合主要覆盖避险、引导、移动、救援与探索。

## 先验证的组合

1. **会急刹的远航者**：可接在现有巨鱼拖船试验后，新增内容主要是附着点与水阻关系。
2. **会暴露自己的测绘师**：可以用一个岔道验证主动探测、暴露和逃离，重点检验声与气味是否读得懂。
3. **把自己的影子卖给海**：视觉潜力高，需要单独验证真实投影、假倒影和分离影子的辨识。

这些优先级属于编辑建议，不等于用户已经授权下一轮游戏实现。
