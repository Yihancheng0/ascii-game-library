# 岩间微光 / Cove scene study 0.1.0

2026-10-21。规范 1.1.0-draft.2 下的 E0/E1 独立场景研究。用户已明确授权先做一屏浅湾：可控灯鱼、六条同种小鱼、巡游大鱼、岩体与共同光照；以实际画面和基本手感讨论下一步。

这份公开笔记是原创设计与验证元数据，不含第三方原鱼源码、参考视频/截图、玩家存档或本机路径。可操作构建留在本地/私有游戏仓库。

## 这一段怎样体验

固定机位的 1280×800 水湾。点击/拖动水面或 WASD/方向键控制灯鱼，空格开关灯，P 暂停，R 重来。小鱼在近距离且看得见光时靠近，绕过岩石跟随；失去线索后搜索一会儿，再低速停留；灯重新出现可重聚。自动观看采用同样输入意图、规则与水域，没有传送和伪造完成。

岩体从有体积的表面采样为字符，同一基础几何派生通行、视线、受光与水线。静态岩面缓存，湿边和光照局部更新；转弯的导航余量、固定节长姿态与全身包络共同避免岩边卡住或鳍尾穿岸。灯器附着身体，鱼、湿岩和附近水面均有光照响应。

大鱼只巡游。本次不含攻击、鱼损失、胜负、双策略、功能伙伴、船人或基地；这是 E1 场景研究，不能当作 E2 护送玩法已成立。所有尺寸、数量和候选形体均未升格为正式参数。

## 验证状态

- 类型检查、仓库原有行为回归通过；默认游戏仍 v0.6.1。
- 离线真实 DOM 事件 + 原生 Canvas：14,862 个固定步进、247.7 秒模拟、572 个全身/鳍尾帧；聚拢、绕岩、全员抵达另一侧、灭灯惯性线索/停留/重聚、隔岩不吸引、输入中断恢复和三个历史存档键隔离通过。
- 同姿态开关灯：湿岩 2,890 像素变化，近水与鱼体 3,536 像素变化，远水对照 0。仅验证局部因果，不评价美感。
- 执行者检查同版本正常、灭灯、无辅助光晕/结构、灰度、缩略和运动采样帧。用户艺术验收 pending，七个正式基准均未自动通过。
- 浏览器控制被 Work 设置关闭，未绕过；实际 DOM 布局、键鼠体验和设备帧率 pending。离线 CPU 绘制耗时不等于浏览器 FPS。
- 原鱼渲染/模拟文件未改；旧 K-01 仍未修复；旧样片与其它工作保持原状。
