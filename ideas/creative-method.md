# 奇特玩法的产生与筛选 / Creative method

状态：设计方法建议。日期：2026-10-20。

## 一次只翻转一条常识

把熟悉活动拆成动词、对象、关系、时间和结果。保留大部分可理解的部分，改变其中一条规则，再推演玩家选择。

| 熟悉规则 | 翻转 | 需要回答的问题 |
|---|---|---|
| 人把鱼拉上船 | 鱼把船拉进海 | 借力、制动和放弃分别在什么情况下合理？ |
| 钩进入真实水域 | 钩只影响倒影 | 怎样移动灯、船和投影，玩家能否看懂？ |
| 岛固定不动 | 岛跟随巨鱼迁徙 | 登岛、停留和离岸有什么预兆？ |
| 鱼获离开生态 | 放生位置改变环境 | 放在哪里，得到什么、失去什么？ |
| 人凭武器战胜鱼 | 只能借另一种鱼对抗 | 感知、运动、光、声与潮汐怎样组合？ |

一个奇特设定需要反复产生不同局面，才能发展成可玩的规则。好看的十秒与有意思的十分钟分别验证。

## 六种角色视角

这是思考分工，不表示必须调用多个 AI，也不保证多角色一定产生好点子。

1. 生物观察者：真实生物行为怎样夸张成可观察、可利用的规律？
2. 魔术师：哪条常识值得翻转，其他规则怎样保持可理解？
3. 动作设计师：手上具体做什么，哪个瞬间有感觉？
4. 美术导演：怎样用十秒画面表现因果，是否保持字符海的美感？
5. 挑剔玩家：第十次会做什么不同选择，有没有可掌握的技巧？
6. 制作人：删除哪些内容，仍能验证核心乐趣；哪项依赖最可能让项目半途停止？

先分别产出，再互相挑错。不要让所有角色只负责赞同同一方案。

## 统一提案卡

- 一句话介绍。
- 玩家实际操作。
- 三种不同局面与选择。
- 最精彩的十秒。
- 十次游玩之后仍存在的变化。
- 最小验证版本与最危险依赖。
- 对原有美术风格的影响。
- 状态：用户提出 / 候选 / 同意试验 / 已验证；完成需要验收证据。

检索关键词：灵感、脑洞、角色扮演、头脑风暴、常识翻转、机制组合、creative constraints、brainstorming、rule inversion。
