# 04 · 世界结构、岛鱼与场景设计

## 4.1 世界设定的层级

已确认：海、岛、船等主体是鱼；天空也可作为巨大鱼体的可见部分，昼夜可由它翻身表现；人类可以在岛鱼背上建房、种树。只有鱼能真正对抗鱼，玩家通过理解、借助和组合鱼的能力行动。

这些是世界规律，并不要求开场同时展示全部奇观。开场先让玩家理解一条生物的呼吸、一束灯和一次回应。天空鱼翻身、海鱼迁徙等大型事件属于未来内容；具体表现和玩法尚未实现。

<a id="WORLD-01"></a>
## 4.2 WORLD-01：地形来自完整身体

岛鱼先有完整生物结构，再从身体表面生成地形。需要画出头部朝向、脊柱或等效支撑结构、鳍根、尾根、呼吸器官、背部承载区域、水线与水下体积。随后才能决定房屋、树、码头在哪里。

至少同时提交：
1. 无房屋、无眼睛装饰的整体轮廓。
2. 水上与水下连续结构图，注明哪些部分被水遮住。
3. 实际游戏镜头下可辨认的身体特征。
4. 呼吸前后同一组地标的位移对照。
5. 玩家路径、建筑基础和生物敏感部位的关系。

判断不是“看见眼睛了吗”，而是“不看标签能否理解这是一具承载了土地的身体”。不能把原有普通岛的距离场原样保留，再附加巨鱼剪影作为解释。

<a id="WORLD-02"></a>
## 4.3 WORLD-02：身体变化必须传递到附属物和玩法

生物动，附着的岸线、湿边、码头基础和通行区必须采用一致的变换来源。房屋可因人类结构而较稳定，但基础不能漂离背部。树有根，叶有自身响应，不能所有物体完全同相。

呼吸不是整座岛缩放。建议从器官动作、局部躯体起伏、进出水流和岸边水位建立可读关系；具体动作幅度先通过样片确定。玩家应能在无需字幕提示的观察中发现其中至少一组联系。

碰撞、导航与可见表面必须同步。若某区域暂不支持动态碰撞，应限制该身体部位的活动并明确其为过渡方案；不能画面起伏、角色仍在不可见的平面上走。

## 4.4 岛鱼体型候选，不在此裁定

| 候选 | 可以利用的结构 | 主要风险 | 对照必须证明什么 |
|---|---|---|---|
| 宽背鳐形 | 宽阔承载面、胸鳍形成湾口 | 远看变成普通薄片岛 | 躯干厚度、鳍根、头尾方向 |
| 覆岩巨鱼 | 背脊岩壳、鳃部港湾 | 岩石完全盖掉鱼形 | 岩壳与身体连接，水下连续 |
| 弯身或盘卧型 | 身体围成港湾 | 曲线太复杂，路径难读 | 体节连续，内外水流可辨 |

选型需要同一视角、同一采样尺度、同一光线的对照，不先把某一候选精雕后拿另一个草图陪衬。具体物种须记录在决策表，避免执行模型各自选择。

<a id="WORLD-03"></a>
## 4.5 WORLD-03：场景采用可解释的空间层次

每个可游玩区域写明水下层、水面、可行走表面、架空结构、前景遮挡和大气效果。渲染、碰撞、导航不必使用同一数据格式，但必须从同一场景定义派生，不能由几个独立手写数组分别决定位置。

遮挡规则必须解释：
- 水下鱼经过码头下方时，哪些身体片段被柱、平台和水体遮住。
- 玩家在栈道上、桥下或岛背上时，哪一层负责承托。
- 巨鱼跨多个区域时，不能按头部位置决定全身是否显示。
- 雾和灯光改变可见程度，不凭空改变碰撞体。
- 半透明水只能在定义好的深度关系中显露水下对象。

Y 排序只适用于它可以表达的平面关系。桥梁、跨层身体和大面积遮挡需要分层或深度掩码，不能所有物体按中心点一排了事。

<a id="WORLD-04"></a>
## 4.6 WORLD-04：巨大海域采用确定性分区，保留重要地点的作者设计

“无限”指玩家可持续探索的逻辑空间，实际内存、计算和存档均有边界。不能承诺数学意义上的无限精度或无限内容。技术方案应支持按需生成、卸载、可重访和远坐标精度管理。

世界种子与区域坐标决定自然内容；命名岛鱼、剧情地点和玩家改动用稳定 ID 保存。加载顺序不得改变岛的外形。玩家离开再返回，救过的鱼、修过的鳃、放置的装饰必须一致。

首个港湾和关键剧情区域先手工控制构图和节奏。程序生成使用经过审核的形体语法、组合和连接约束；不能无限平铺同一个漂亮片段，也不能把所有位置随机化。未完成的海域在开发菜单中明确标为原型，不以世界地图图标假装已经可玩。

分区边界必须覆盖：半条鱼跨区、船与同伴分别跨区、光源照到邻区、岛鱼跨多个区、存档后在边界重载。每种情况都要确定归属与邻区引用。

<a id="WORLD-05"></a>
## 4.7 WORLD-05：天气和昼夜是共同状态，不能只覆盖一层特效

天气状态驱动海面、植被、灯光能见度、声音和部分鱼行为。最低完整天气片段应包含开始、发展、峰值和消退，以及至少一个可感知的环境响应。雨线叠加不等于完成风暴。

天空鱼翻身属于世界事件候选；不能为了昼夜循环让天空鱼高频翻滚。昼夜速度、天气频率、风暴对航行的影响待讨论与试玩。开场默认安静，事件变化应有预兆，不以突然白屏制造“高级感”。

天气可以影响路径和机会，但首次教学不能被随机大浪或闪电打断到无法完成。无障碍的低闪烁、低抖动模式要保留同样的危险信息。

## 4.8 人类建筑与自然的关系

建筑无需长鱼脸。美感来自它如何坐落在活体世界：基础避开鳃口，栈道留出呼吸水道，房屋朝向背脊，材料因潮湿和移动而有结构选择。树根可适应背部地形，不能直接扎进裸露眼睛等敏感器官而没有设定依据。

装饰鱼应有栖息、承载、光源或功能关系。挂在船边的灯鱼可选择停驻与同行，不能一装备就成为静止挂件。岛上鱼群装饰必须留出活动范围与避让，不得遮住操作目标。

## 4.9 内容扩张的准入

每个新海域只引入足以形成区别的主要规律，并与已学能力发生联系。进入前写清：视觉差异是什么、玩家能做什么、为什么回来、失败如何恢复。仅改变背景颜色不构成新区域；增加一串新名词也不构成新玩法。

<a id="WORLD-06"></a>
## 4.10 WORLD-06：护送水域先有空间选择，再做景观扩展

首段采用一个手工设计的连续水域。构图需包括可试光的起点、可观察的危险区、容量合适的掩护、可判断的通路和可见的安全终点。它们必须构成有体积的海中地形，不用漂浮圈、箭头和文本标签代替空间设计。

对每条路记录：灯鱼与队伍是否可通行、捕食者是否可通行、视线在哪里被挡、队尾会在哪里暴露、掉队后是否可返回。有些缝隙可让小鱼通过而挡住大鱼，但差异应由身体和地形尺度看得出；不能同一条大鱼一会穿过、一会因脚本被禁止。

不以挤窄到寻路经常失败的入口制造挑战。首段没有硬倒计时，玩家可在真正安全处观察；如果开阔水域会持续受威胁，用巡游和空间关系表达。保持一次威胁后有恢复观察的节奏，不把整个海域变成永不休息的追逐场。

这里可以是未来岛鱼周围的一角，不要求先做完整岛鱼模型；不得把未经结构验证的普通小岛称为最终岛鱼。大世界、港湾建造与章节扩张仍受原有规则约束，已获方向认可不等于必须在第一段全部出现。
