# 03 · 美术与字符表现标准

本章约束观看结果与制作方法的关系。最终表现是二维 ASCII 海洋；建模工具、缓存或离屏画布属于实现手段。不能只凭代码里使用了字符，就宣布符合风格。

## 3.1 美感来自哪些相互支撑的关系

原鱼的吸引力可以拆成六件事：远看完整、近看丰富的轮廓；头、脊柱、身体、鳍尾之间的结构；身体明暗让人读到厚度；字符在局部变化而大形稳定；水流和拖影延续运动；暗处留白让微小亮点有分量。某一个环节的复杂度不能代替另外五个环节。

环境要达到同一水平，不能仅把岩石、树、屋顶分别转成字符图再摆进去。它们需要共同的空间、照明、水位和时间。例如岸边的礁石，要有迎光面与背光面、浸水线、随波变化的接触水纹、被遮挡的水下部分；其中任何一层单独看都不需要特别花哨。

“像贴纸”在本项目中指以下可观察症状：物体没有体积和结构；内部明暗与环境光不一致；边缘没有接触关系；动作只是整块移动；不同物体字符比例突变；透过实体仍能看见完整的别的物体。它不是对所有二维贴图、精灵或缓存的技术禁令。

<a id="ART-01"></a>
## 3.2 ART-01：形体先于字符细节

每个主要对象先提交黑白轮廓和结构稿，关闭闪光、粒子、文字、眼睛装饰。测试近、中、远三个实际游戏视距，而不是只看放大的宣传截图。

合格条件：
- 鱼的前后、背腹、尾鳍方向可辨；主要体块的连接点明确。
- 岛鱼从头、躯干、鳍、尾的整体结构形成可用地形；删掉眼睛仍具有生物姿态。
- 船鱼具有承载和前进结构；驾驶位与水线存在可信关系。
- 灯鱼在实际像素尺寸下能看出身体、头部和发光器官，不靠名字解释。

失败例：岛周围多放几片鳍，岛内部完全不变；小船仅用一根字符线加人物；锁鳞用几个悬空字母表示。处理顺序是重做结构与尺度，不能先添加粒子或说明气泡。

<a id="ART-02"></a>
## 3.3 ART-02：字符必须表达表面、方向与深度

字符承担亮度、表面疏密和方向信息。生成流程应能回答：这个位置属于什么表面；法线或等效朝向是什么；光从哪里来；该用哪一级密度；运动时如何保持同一块表面的身份。无需每个对象都做复杂三维模型，但不能完全依赖与材质无关的随机字符。

材质建议语法属于待验证配方：
| 材质 | 结构信息 | 字符变化原则 | 禁止用来凑数的办法 |
|---|---|---|---|
| 鱼皮 | 脊背到腹部的体积、鳞向 | 大明暗稳定，少量局部闪烁 | 全身每帧独立随机 |
| 潮湿岩壳 | 大块面、裂隙、水线 | 面内较稳定，湿边变化 | 满屏同强度噪声 |
| 木构 | 梁柱、板向、受力连接 | 沿材料纹理分布 | 屋顶和地面同一铺法 |
| 草木 | 茎、叶簇、生长方向 | 根稳定，末梢有层次摆动 | 整片平移或同相钟摆 |
| 水 | 流向、深度、接触扰动 | 较稀疏，波纹有传播方向 | 一张不变的花纹盖满海面 |
| 发光器官 | 有边界的实体与内部光源 | 核心明确，光晕有衰减 | 无实体的泛光圆点 |

不规定只能使用 7 位 ASCII。沿用原鱼的字符语言，正式字库在基准校准后冻结。新增字符必须验证字体支持、笔画重量、基线和整体密度；不能混入风格突兀的 emoji 或缺字方框。字符表、字体版本和回退策略应纳入证据。

<a id="ART-03"></a>
## 3.4 ART-03：字符比例和采样必须稳定

共享的是比例逻辑，不是要求远近所有对象用同一字号。对象的结构尺度、投影尺度、字符采样尺度分开定义；同一景深的相邻物体不应突然出现一块巨大网格和一块细碎印刷纹。

允许不同距离层级、物种细节级别。切换时轮廓不应跳变，字形不能随着镜头拖动反复重排成另一张脸。最小识别尺度不足时，减少细节，保留主形；不要靠把全图锐化补救。

需要在浏览器实际缩放、设备像素比、字体加载完成前后验证。不能把离屏图放大之后产生的格子、模糊或不等宽误当成新风格。镜头取整、字格对齐、缓存分辨率应由同一个投影策略管理。

<a id="ART-04"></a>
## 3.5 ART-04：照明和接触关系属于整个场景

所有可见主体应响应同一组有效光源。灯鱼靠近岩石时，光源位置、岩石受光面、水面的亮痕和鱼自身亮度应建立因果联系。光线不能越过实体山体把背面照亮，除非该材质明确允许透光。

柔和光晕、雾与后处理可作为辅助，但应服务字符形体。关掉辅助效果后仍能看出实体；打开后不能把轮廓吞没成一团乳白色。不要为了“纯 ASCII”把原鱼已有的气氛全部删掉，也不能把普通渐变插画上覆字符当作完成。

接触必须单独检查：脚与地、船与水、岛与水、梁与柱、鳍与身体。接触点至少有可信的遮挡、承托或扰动证据；无需所有地方同时加接触阴影。

<a id="ART-05"></a>
## 3.6 ART-05：颜色、留白和信息层级共同受控

安静深海是主气质，黑色不是唯一允许的底色。晨光、雾湾、暖灯和风暴都可以改变环境，但需要保留低噪声背景、清楚主形、有限强调色的关系。色值和比例待样片校准，不把任意“百分之几亮色”写成真理。

一帧中先读到玩家、当前可操作对象和危险，再读到次要景观。装饰不能持续抢走视线。大量稀有彩色字符、满屏泛光、多个发光机关并列，都应在缩略图审查中被发现。

执行者须提交：正常图、灰度图、缩略图、关闭特效图。灰度图检查体块是否靠颜色勉强分开；缩略图检查主次；关闭特效图检查基础造型。它们是诊断图，不代表必须交给玩家显示。

<a id="ART-06"></a>
## 3.7 ART-06：轮廓稳定，局部变化有归属

鱼身“字符在蹦”不等于整条鱼每帧重抽纹理。稳定的大轮廓、连续的亮面、局部错开的变化，才会产生有机的闪烁。随机必须绑定对象、身体位置和连续时间，而非镜头位置或遍历顺序。

同一物体的主明暗不应在无光源变化时突然反转。环境表面默认比活体稳定；湿边、叶尖、发光器官、尾迹可更活跃，但均有物理或生物来源。闪电等事件允许短时强变化，必须有范围、恢复过程与低闪烁选项。

## 3.8 交付一个对象的美术证据

依次交：轮廓三视距；结构和承托图；静态明暗；字符版；动作片段；放进实际海域的接触与遮挡；含玩家操作的完整镜头。每一步标出“这一轮改了什么”，保存上一个可用版本。

评审者应指出具体断裂关系，例如“尾鳍的轴心没有跟随尾根”“灯照亮水却没有照亮邻近船侧”。“还不高级”不能直接作为可执行修复单；需要转成构图、体块、材质、动画或反馈中的一个明确问题。
